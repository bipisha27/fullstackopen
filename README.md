# Full Stack Open

This repository contains my exercises and assignments from the Full Stack Open (https://fullstackopen.com/en/) course by the University of Helsinki.

The repository includes work from Parts 0–7, including topics such as:

* JavaScript and modern web development
* React
* Node.js and Express
* REST APIs
* MongoDB
* React state management
* Testing
* TypeScript fundamentals

The repository contains my completed exercises and assignments from the course.

## Technologies

JavaScript, React, Node.js, Express, MongoDB, TypeScript, Git, and GitHub.
